# WPFW programmer directory

`programmers.js` is the directory embed. A Squarespace page carries it
in one line:

    <script src="https://wpfwgm.github.io/wpfw-programmer-data/programmers.js"></script>

`programmers.json` is what it reads: names, photographs, biographies and
past episodes. Everything here is already public on wpfwdc.org.

Both are generated. Do not edit them here -- edit the Programmer
Directory project and run `node tools/update.js`.
